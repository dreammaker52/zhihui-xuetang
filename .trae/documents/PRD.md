# 专属 AI 陪聊网页 - 产品需求文档

## 1. 产品概述

复刻本人性格、说话语气、日常聊天风格的专属 AI 陪聊网页。用户可通过公开网址访问，底层调用外部大模型 API 驱动对话，保留完整管理员后台功能。

**核心价值：** 无需复杂配置，即可拥有1:1还原本人说话风格的 AI 陪聊助手，支持一键部署公开访问。

---

## 2. 功能模块

### 2.1 用户角色

| 角色 | 访问方式 | 核心权限 |
|------|----------|----------|
| 普通访客 | 直接访问首页 | 仅限聊天，无管理权限 |
| 管理员 | /admin 路径 + 独立密码 | 完整后台功能 |

### 2.2 功能列表

#### 前台聊天页面
- **聊天界面**：简洁干净的界面，流畅的聊天体验
- **手机适配**：响应式布局，完美适配移动端
- **人设展示**：显示当前 AI 人设简介
- **公开访问**：生成外网链接直接分享

#### 管理后台
- **密码登录**：独立私密管理密码
- **实时监控**：查看所有用户聊天记录、发言时间、双方内容
- **用户区分**：清晰区分不同聊天用户
- **手动接管**：随时顶替 AI 回复，无缝切换
- **人设修改**：实时修改 AI 性格、语气、口头禅等，实时生效
- **内容管控**：暂停服务、拉黑用户、限制内容、屏蔽词汇
- **历史记录**：查看全部历史对话，简洁排版
- **模型配置**：填入 API 地址、密钥、切换模型

---

## 3. 核心流程

### 3.1 普通用户聊天流程

```
用户访问首页 → 输入昵称 → 开始聊天 → AI 回复 → 持续对话
```

### 3.2 管理员后台流程

```
访问 /admin → 输入密码 → 进入后台 → 选择功能模块 → 操作
```

### 3.3 手动接管流程

```
后台查看当前对话 → 点击接管 → 输入回复内容 → 发送 → 用户看到 AI 回复
```

## 5. 界面设计

### 5.1 设计风格
- **整体风格**：简洁现代，暗色系为主
- **配色方案**：
  - 主色：#6366f1（靛蓝）
  - 次色：#8b5cf6（紫色）
  - 背景：#0f0f0f（深黑）
  - 文字：#e5e5e5（浅灰）
  - 强调：#f472b6（粉色）
- **圆角风格**：中度圆角 (8-12px)
- **字体**：系统默认字体，简洁易读

### 5.2 页面结构

#### 首页（聊天页面）
- 顶部：AI 人设简介 + 状态指示
- 中部：聊天消息区域（滚动）
- 底部：输入框 + 发送按钮
- 右下角：最小化后台入口

#### 管理后台
- 左侧：功能导航
- 右侧：内容展示区
- 顶部：退出登录

### 5.3 响应式设计
- 桌面端：最大宽度 800px 居中
- 移动端：全宽布局，底部输入框固定

## 6. 技术架构

### 6.1 技术栈
- **前端**：React 18 + TypeScript + TailwindCSS
- **后端**：Express.js 4
- **数据库**：SQLite（轻量级，文件存储）
- **实时通信**：Server-Sent Events (SSE)

### 6.2 路由设计

| 路径 | 功能 |
|------|------|
| / | 聊天首页 |
| /admin | 管理后台（需密码） |

### 6.3 API 设计

#### 聊天相关
- `POST /api/chat` - 发送消息
- `GET /api/chat/history/:sessionId` - 获取历史记录
- `GET /api/chat/sessions` - 获取所有会话

#### 管理相关
- `POST /api/admin/login` - 管理员登录
- `GET /api/admin/chats` - 获取所有聊天记录
- `POST /api/admin/takeover` - 手动接管对话
- `PUT /api/admin/persona` - 修改人设
- `PUT /api/admin/settings` - 修改系统设置

#### 配置相关
- `GET /api/admin/config` - 获取 AI 配置
- `PUT /api/admin/config` - 更新 AI 配置

---

## 7. 数据模型

### 7.1 会话 (Session)
```
id: string
visitorName: string
createdAt: timestamp
lastMessageAt: timestamp
```

### 7.2 消息 (Message)
```
id: string
sessionId: string
role: 'user' | 'ai' | 'admin'
content: string
createdAt: timestamp
```

### 7.3 配置 (Config)
```
adminPassword: string
aiPersona: object
modelConfig: object
serviceEnabled: boolean
bannedUsers: string[]
```
