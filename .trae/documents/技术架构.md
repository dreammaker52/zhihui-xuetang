## 2. 技术选型

| 层级 | 技术 | 说明 |
|------|------|------|
| 前端框架 | React 18 + TypeScript | 组件化开发 |
| 构建工具 | Vite | 快速热更新 |
| 样式 | TailwindCSS | 原子化 CSS |
| 状态管理 | Zustand | 轻量级状态管理 |
| 后端框架 | Express.js 4 | Node.js 服务端 |
| 数据库 | SQLite + better-sqlite3 | 轻量级文件数据库 |
| 实时通信 | Server-Sent Events | 聊天消息推送 |

## 4. 数据库设计

### 4.1 sessions 表
```sql
CREATE TABLE sessions (
  id TEXT PRIMARY KEY,
  visitor_name TEXT NOT NULL,
  created_at INTEGER NOT NULL,
  last_message_at INTEGER NOT NULL
);
```

### 4.2 messages 表
```sql
CREATE TABLE messages (
  id TEXT PRIMARY KEY,
  session_id TEXT NOT NULL,
  role TEXT NOT NULL,
  content TEXT NOT NULL,
  created_at INTEGER NOT NULL,
  FOREIGN KEY (session_id) REFERENCES sessions(id)
);
```

### 4.3 config 表
```sql
CREATE TABLE config (
  key TEXT PRIMARY KEY,
  value TEXT NOT NULL
);
```

## 5. API 详细设计

### 5.1 聊天 API

#### POST /api/chat
发送消息并获取 AI 回复

**请求体：**
```json
{
  "sessionId": "xxx",
  "visitorName": "小明",
  "message": "你好啊"
}
```

**响应：**
```json
{
  "success": true,
  "data": {
    "sessionId": "xxx",
    "messages": [...]
  }
}
```

#### GET /api/chat/history/:sessionId
获取指定会话的历史记录

#### GET /api/chat/sessions
获取所有会话列表

### 5.2 管理 API

#### POST /api/admin/login
管理员登录

**请求体：**
```json
{
  "password": "admin123"
}
```

#### GET /api/admin/chats
获取所有聊天记录（需登录）

#### POST /api/admin/takeover
手动接管对话

**请求体：**
```json
{
  "sessionId": "xxx",
  "message": "我来亲自回复你"
}
```

#### PUT /api/admin/persona
修改 AI 人设

**请求体：**
```json
{
  "persona": {
    "age": 17,
    "personality": "...",
    "catchphrases": ["wtf", "神了"],
    "forbidden": ["伤害她自尊的话"]
  }
}
```

#### PUT /api/admin/settings
修改系统设置（暂停服务、拉黑用户等）

#### GET /api/admin/config
获取 AI 模型配置

#### PUT /api/admin/config
更新 AI 模型配置（API 地址、密钥等）

## 6. AI 对接设计

### 6.1 模型配置
```typescript
interface ModelConfig {
  apiUrl: string;      // API 地址
  apiKey: string;      // API 密钥
  model: string;       // 模型名称
  systemPrompt: string; // 系统提示词（人设）
}
```

### 6.2 人设注入
每次请求 AI 时，将人设作为 system prompt 注入，确保 AI 回复符合指定风格。

### 6.3 调用流程
```
用户消息 → 构建 Prompt（含人设）→ 调用外部 AI API → 返回回复 → 存储并推送
```

## 7. 部署方案

### 7.1 开发模式
```bash
npm run dev
# 前端: http://localhost:5173
# 后端: http://localhost:3001
```

### 7.2 生产部署
```bash
npm run build
npm start
# 前后端合一，通过 Express 服务静态文件
```

### 7.3 外网访问
部署后可通过服务器公网 IP 或域名直接访问聊天页面，分享链接即可。
